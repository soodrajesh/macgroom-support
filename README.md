# MacGroom Support

Public issue tracker and changelog for the [MacGroom](https://gogenops.com/mac-apps/macgroom/) suite of native macOS utilities — DiskSweeper, Toolbox, MacTools, DupeFinder, and SnapText.

This repo doesn't contain app source — it exists so bugs and feature requests have a real, free place to live instead of getting lost in email.

## Found a bug or have a request?

[Open an issue](../../issues/new/choose) — pick Bug Report or Feature Request.

## Other ways to reach us

- **Website & Contact form:** https://gogenops.com/mac-apps/macgroom/
- **Email:** via the Contact form on the site above

## Releases & changelog

Each app's release notes will be published here once public updates begin — see [Releases](../../releases).

## Privacy

Every MacGroom app runs 100% locally. Nothing you scan, clean, or find is ever uploaded anywhere — see each app's own README for the exact commands it runs.
